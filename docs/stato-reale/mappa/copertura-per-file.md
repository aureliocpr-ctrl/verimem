- **qual** — un import lega il nome a quel modulo: attribuzione **certa**

- **rif** — nominata senza parentesi (`target=f`, decoratori, dispatch):
  eseguita o no, il righello non può dirlo

`pytest --cov=verimem.<modulo> --cov-report=term-missing` sul perimetro dei
